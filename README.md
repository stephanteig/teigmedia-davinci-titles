# TeigMedia DaVinci Titles

DaVinci Resolve title presets from TeigMedia.

The bundled DRFX library is:

- `TeigMedia DaVinci Titles Library.drfx`

Included titles:

- TeigMedia Social Safezones
- TeigMedia CMYK Glitch Text
- TeigMedia Slot Machine Text
- TeigMedia Flow Logo
- TeigMedia Flow Dots
- TeigMedia Audio Waveform
- TeigMedia Animated Sound Wave

Install the DRFX by opening it with DaVinci Resolve or dragging it into the Fusion page.
