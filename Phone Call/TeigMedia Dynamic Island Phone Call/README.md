# TeigMedia Dynamic Island Phone Call

An animated iPhone Dynamic Island incoming-call macro for DaVinci Resolve.

## Included versions

- **Fusion:** `Fusion/TeigMedia Dynamic Island Phone Call/`
- **Edit Page:** `Edit/Titles/TeigMedia/TeigMedia Dynamic Island Phone Call/`

Both versions include the bundled profile image and expose the same controls:

- Caller name and call label
- Dark/light mode
- Layout and button positions
- Colors
- Answer After (seconds)
- Animation Speed

## Installation

1. Download the `.drfx` release file.
2. Double-click it or import it through DaVinci Resolve.
3. Restart Resolve if the template does not appear immediately.
4. Use the Fusion version in Fusion, or the title version from the Edit Page Effects Library.

The release package includes the image asset, so it does not depend on the original development-volume path.
